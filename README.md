# 纸盒小景 · 造景贴纸游戏

双击 `index.html` 就能玩（走 file://，不用起服务器；标题字体从 Google Fonts 拉，断网会退回系统字体）。

## 玩法

- **贴**：从右边贴纸册把贴纸拖进纸盒。地面贴纸放得越靠下越大、越靠前；天上的贴纸挂在盒子里，太阳/月亮/彩虹/星星贴在后墙上。点一下贴纸册里的贴纸也能直接贴。
- **改**：点盒子里的贴纸，会出现工具条（翻转 / 缩小 / 放大 / 复制 / 撕掉）。滚轮缩放、F 翻转、Ctrl+D 复制、Delete 撕掉、Ctrl+Z 撤销；拖出盒子等于撕掉。
- **反应**：贴纸之间会起反应，一共 24 种，记在「图鉴」里，没发现的会给线索。拖着贴纸靠近能反应的搭档时，搭档会冒金光。
  - 雨云＋树苗 → 长成大树；雨云＋池塘 → 跳出青蛙（解锁青蛙）；夏天青蛙在池塘边 → 荷花
  - 雨云＋太阳 → 彩虹；秋天雨云＋大树 → 蘑菇；冬天雪云＋石头 → 雪人
  - 小鸟＋大树 → 筑巢；猫＋小鸟 → 鸟飞走（解锁飞鸟）；猫＋长椅 → 午睡（点长椅能叫醒）
  - 春天两只鸭子 → 小鸭；春天花丛 → 蝴蝶；夏夜草丛 → 萤火虫；夜晚月亮＋长椅 → 流星（解锁星星）
  - 小桥架在池塘上 → 解锁小船，等等
- **季节 / 时段**：顶上切春夏秋冬、白天黄昏夜晚。树、草、池塘、兔子会换季，夜里窗户和路灯会亮。
- **委托**：右下角的委托卡列出客人的要求，全部打勾就能「交付」，按加分项给 1–3 星，同时拍一张照片进相册。共 9 个委托。
- **相册**：「拍照」把当前盒子存进相册（存在 localStorage，最多 24 张），可以下载。

进度（场景、图鉴、委托、解锁）自动存在浏览器 localStorage 里。

## 文件

| 文件 | 内容 |
|---|---|
| `index.html` | 页面结构和样式 |
| `js/art-core.js` | 调色板、画笔、烘焙（墨线外轮廓＋白色模切边＋投影、点选遮罩） |
| `js/art-nature.js` | 植物、地形、建筑类贴纸画法（15 张） |
| `js/art-critters.js` | 动物、天空类贴纸画法（16 张） |
| `js/world.js` | 纸盒几何、贴纸定义 `DEFS`、渲染、粒子、昼夜叠色 |
| `js/rules.js` | 反应规则、图鉴 `DISC`、委托 `JOBS` |
| `js/ui.js` | 贴纸册、拖放、选择、撤销、弹窗、拍照、主循环、`window.__TEST__` |
| `js/audio.js` | WebAudio 现场合成的音效（撕、贴、叫声、雨声…） |
| `sheet.html` | 贴纸预览表：`sheet.html?only=tree,duck&zoom=1.5` |
| `tools/shot.py` | 截图：`python tools/shot.py index.html shots/x.png 1440 900` |
| `tools/play.py` | 脚本化试玩（无头浏览器里的鼠标）：`python tools/play.py basic|combos|flow` |

所有贴纸都是代码画的，不依赖图片文件。加一张新贴纸：在 art 文件里 `ART.add(id, (g, v) => {...}, previews)`，再到 `world.js` 的 `DEFS` 登记名字、分类和所在区域。
